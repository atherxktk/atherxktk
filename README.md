### 🚀 Featured Projects

#### 🤖 Heterogeneous Swarm Robotics Platform (Custom Dual-MCU PCB)
*Designed an omnidirectional coordinator robot from scratch for swarm research.*
* **Architecture:** Bare **STM32F411** (real-time motion control & encoder feedback) paired with an **ESP32-WROOM-32** (wireless comms & swarm coordination) communicating over UART.
* **Motion & Power:** Mecanum wheel drive powered by N20 magnetic encoder motors and **TB67H451AFNG** motor drivers, featuring custom RC low-pass filtered PWM-to-analog VREF circuits for dynamic current limiting.
* **PCB Engineering:** Designed in EasyEDA Pro with dedicated RF keepout zones, optimized power trunks, and a cost-effective BOM tailored for automated SMT assembly.

#### 🏎️ Multi-Sensor Autonomous Line-Following Robot (LFR)
*Competition-grade autonomous robot built for high-speed tracking and hazard detection.*
* **Hardware:** Arduino Nano-based architecture integrating a 5-channel IR sensor array, ultrasonic obstacle detection, flame sensing, and an L298N motor driver.
* **Engineering Focus:** Clean power-rail isolation, optical shrouding/ambient IR mitigation, and structured pin-mapping for reliable real-time sensor polling.
